# Archive

`archive/` holds information that is no longer current but is still safe and useful to keep for historical explanation.

## When to Archive

Move information here when it:

- is no longer current,
- is too detailed for canonical context (would clutter `context/` or `projects/` without adding present-day value),
- remains useful for explaining *why* something is the way it is now, and
- would confuse a future model if left sitting in active context.

## When Not to Archive

Do not use this as a dumping ground. If information should no longer exist at all — for privacy reasons, because it was wrong, or because it was requested to be deleted — remove it outright (per `SECURITY.md` / `CLAUDE.md`), don't archive it. Archiving is for things worth keeping; deletion is for things that aren't.

## Format

When archiving a file or section, keep its original content close to intact and add a short note at the top: what it was, why it moved here, and the date. Link back to whatever superseded it, if applicable, from `decisions/decisions.md` or the relevant `context/`/`projects/` file.
